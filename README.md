# Mudre misli (мѫдрыѩ мысли)

Житиꙗ и мнѣніꙗ знаменитыхъ любомѫдрьць (Житиꙗ любомѫдрьць)

## Development

```
npm run dev
```

Production build:

```
npm run build
npm start
```
