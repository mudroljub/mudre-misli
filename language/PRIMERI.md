# ПРИМЕРИ СТАРОСЛОВЕНСКОГ ФИЛОСОФСКОГ ЈЕЗИКА

Издвојени примери из корпуса за реконструкцију словенског философског језика.

Правила издвајања:
- Тражени су примери са философским или апстрактним значењем
- Предност дата дефиниционим реченицама, апстрактним именицама и преводима грчких појмова
- Сачувана је оригинална ћирилица (ѣ, ѧ, ѫ, ѹ, ꙗ, ѭ)

---

## СЛОВО

### Грчки појам
λόγος (logos)

### [ПОТВРЂЕНО] Прогласъ, р. 26-28

**Текст:**
```
СЛОВО ЖЕ КРЪМѦ ЧЛОВѢЧЬСКꙐѨ ДОУШѦ,
СЛОВО ЖЕ КРѢПѦ И СРЬДЬЦЕ И ОУМЪ,
СЛОВО СЕ ГОТОВАѨ БОГА ПОЗНАТИ.
```

**Зашто је важан:**
Тројна дефиниција слова: (1) храна за душу, (2) јача срце и ум, (3) припрема за сазнање Бога. Показује вишеслојност појма *слово* — није само говор, већ ontološки принцип.

---

### [ПОТВРЂЕНО] Прогласъ, р. 51-56

**Текст:**
```
СЕ БО СВѦТꙐИ ПАВЬЛЪ ОУЧѦ РЕЧЕ:
МОЛИТВѪ СВОѬ ВЪЗДАѨ ПРѢЖДЕ БОГОУ,
ꙖКО ХОШТѬ СЛОВЕСЪ ПѦТЬ ИЗДРЕШТИ
СЪ РАЗОУМОМЬ СВОИМЬ ГЛАГОЛАТИ,
ДА И ВЬСЕ БРАТЬꙖ РАЗОУМѢѬТЪ,
НЕЖЕ ТЬМѪ СЛОВЕСЪ НЕРАЗОУМЬНЪ.
```

**Зашто је важан:**
Супротставља *словеса съ разоумомь* и *словеса неразоумьнъ*. Разумност није само формална исправност, већ способност да језик буде схваћен.

---

### [ПОТВРЂЕНО] Прогласъ, р. 65

**Текст:**
```
ѤГДА СЛОВЕСЕ БОЖІꙖ НЕ СЛꙐШИТЪ.
```

**Зашто је важан:**
*Словесе Божіꙗ* — божанска реч као извор живота душе (у контексту р. 63-65).

## РАЗОУМЪ / РАЗУМЪ

### Грчки појам
νοῦς (ум, разум), διάνοια (мишљење)

### [ПОТВРЂЕНО] Прогласъ, р. 39

**Текст:**
```
КАКО БОЖЬѤ ЧЮДО РАЗОУМѢѤТЕ?
```

**Зашто је важан:**
*Разоумѣти* — способност схватања божјег чуда. Није само логичко разумевање, већ духовна способност.

---

### [ПОТВРЂЕНО] Прогласъ, р. 48

**Текст:**
```
ДА НЕ ИМѪШТЕ ОУМЪ НЕРАЗОУМЬНЪ
```

**Зашто је важан:**
Супротставља *оумъ* и *неразоумьнъ* — постоји ум који не разуме. Разум није исто што и ум.

---

### [ПОТВРЂЕНО] О письменьхъ, р. 86

**Текст:**
```
божꙇимь и чловѣчьскꙑимь вещемь разꙋмь, елико можеть чловѣкь приближити се боѕѣ
```

**Зашто је важан:**
Дефиниција филозофије као *разума божјих и човечјих ствари*, колико човек може да се приближи Богу.

## МОУДРОСТЬ

### Грчки појам
σοφία (софија, мудрост)

### [ПОТВРЂЕНО] Разуми на елинските философи, р. 2

**Текст:**
```
въ ꙁрьцалѣ ꙋбо обраꙁ поꙁнавает се въ бѣсѣдах же паче оумъ.
```

**Зашто је важан:**
У огледалу препознајеш образ, али у разговору открива се ум — *оумъ* се показује у дискусији, не у физичком изгледу.

---

### [ПОТВРЂЕНО] Пчела, р. 67-69

**Текст:**
```
Смѣшно е иже г҃лѥт ꙗко моудрѡст беꙁь ꙋченїа е. Беꙁ нѥе бо нѣпольꙁы ѿ инѣх хытростїи. Та бо е влдка и красота и чинь въсѣм съ подобїемь когождо исправлꙗеть.
```

**Зашто је важан:**
Мудрост је: (1) стиче се учењем, (2) влада свим вештинама, (3) лепота и ред, (4) свако поставља на своје место.

---

### [ПОТВРЂЕНО] Пчела, р. 73-74

**Текст:**
```
Иже въ сем житѣи꙼сцем пеци се паче о моудрѡсти. да въмѣстишїи вѣлико въ мале, оума бл҃га въ малѣ тѣле.
```

**Зашто је важан:**
Тело је мало, али може садржати велики *оумь бл҃гь* — апстракција величине духа у материјалном ограничењу.

## ЕСТЬСТВО / СѪЩЬСТВО

### Грчки појам
οὐσία (усија, битност), φύσις (природа)

### [ПОТВРЂЕНО] Пчела, р. 12

**Текст:**
```
Въсакаа творимаа бл҃гть соущаство имѣет еже въсегда се творить а не еже сътворила се естъ.
```

**Зашто је важан:**
Дефиниција *соущаства* врлине — *сѫщаство* није оно што је једном учињено, већ оно што се непрестано чини. Битност је у трајању, не у једном чину.

---

### [ПОТВРЂЕНО] О письменьхъ, р. 87

**Текст:**
```
ꙗко же дѣтелию оучить чловѣка по ѡбразꙋ и по подобию бꙑти сътворꙿшомоу и
```

**Зашто је важан:**
Филозофија учи човека да *делом* постане *по обрaзу и по подобију* Створитељу — не само знањем, већ праксом.

## ИСТИНА

### Грчки појам
ἀλήθεια (алетеја)

**Текст:**
```

```

**Зашто је важан:**
*Разꙋмь истинꙿнꙑи* — истински разум. Спасење није само у знању, већ у доласку у истинско разумевање.

## ПОЗНАТИ / ВѢДѢТИ / ЗНАТИ

### Грчки појам
γινώσκειν (гиноскеин), γνῶσις (гноза)

### [ПОТВРЂЕНО] Прогласъ, р. 9

**Текст:**
```
БОГА ЖЕ ОУБО ПОЗНАТИ ДОСТОИТЪ.
```

**Зашто је важан:**
*Познати Бога* као врховни циљ. *Познати* није исто што и *знати* — већ лично, директно сазнање.

---

### [ПОТВРЂЕНО] Прогласъ, р. 28

**Tekst:**
```
СЛОВО СЕ ГОТОВАѨ БОГА ПОЗНАТИ.
```

**Зашто је важан:**
Слово припрема за познање Бога — језик је пут ка сазнању.

---

### [ПОТВРЂЕНО] О письменьхъ, р. 17-20

**Текст:**
```
жидове бо прьвое писмѧ имѫтъ алефъ · еже сѧ съкаꙁаетъ оучение · съврашаѭще въводимоу дѣтищю · и глаголѭще · оучи сѧ
```

**Зашто је važан:**
Прво слово азбуке значи *учење* — алеф/азь као позив на учење.

## КНИГꙐ / БОУКЪВꙐ

### [ПОТВРЂЕНО] Разуми на елинските философи, р. 40-43

**Текст:**
```
моудрь беꙁь книгѥ подобьнь е плотꙋ беꙁ подъпора. беꙁ вѣтра стоить а въ вѣтрь падеть. Бѣꙁ книге моуж ꙗко пьтица беꙁ перїа. ꙗко бо она обѣшает и не можеть въꙁлѣтети тако же и оумь не може домꙑслит се беꙁ книге.
```

**Зашто је важан:**
Три аналогије: (1) мудрац без књига = тело без потпоре; (2) човек без књига = птица без крила; (3) ум не може *домꙑслити се* без књига.

---

### [ПОТВРЂЕНО] Прогласъ, р. 91

**Текст:**
```
БОУКЪВИ СІѨ, ИЖЕ БО ПРЇИМЕТЪ
```

**Зашто је важан:**
*Боукъви* — слова као духовно оружје против непријатеља (контекст р. 88-94).
